# Деяния Тренера

Некролог AngryCoachBot («Тренер»): 26.04 — 16.10.2026, пять курсов (планка, стульчик, отжимания, пресс, бёрпи),
39 воспитанников, 211 наград, 65 555 повторений.

**Страница:** https://nikitadalian.github.io/AngryCoachFuneral/

## Файлы

- `index.html` — собранная страница
- `src/template.html` — разметка, стили, тексты
- `src/people.json` — реестр воспитанников (итоги по курсам, награды)
- `src/tickers.json`, `src/botlines.json` — бегущие строки людей и Тренера
- `src/extract.py` — сборка реестра из лендингов прошлых курсов
- `src/build.py` — сборка страницы: `python src/build.py`
